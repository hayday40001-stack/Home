# ของในบ้าน 🧊🏡

เว็บแอพจัดการบ้าน: ตู้เย็น, รายการซื้อ, เมนูจากของที่มี, ทำความสะอาด, รดน้ำต้นไม้, รอบเปลี่ยนของใช้ และค่าไฟ (น้องไฟ)

ทั้งแอพอยู่ในไฟล์ `index.html` ไฟล์เดียว ไม่ต้องติดตั้งหรือ build อะไรเพิ่ม

## ไฟล์ในโปรเจกต์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวแอพทั้งหมด |
| `manifest.webmanifest` | ให้กด "เพิ่มไปยังหน้าจอโฮม" แล้วเปิดแบบแอพได้ |
| `icon.svg`, `icon-180.png`, `icon-192.png`, `icon-512.png` | ไอคอนแอพ |

## ขึ้น GitHub Pages

1. สมัครหรือเข้าสู่ระบบที่ github.com
2. กด **New repository** ตั้งชื่อ เช่น `home-tracker` แล้วเลือก **Public**
3. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป จากนั้นกด **Commit changes**
4. ไปที่ **Settings > Pages**
5. ตรง **Source** เลือก **Deploy from a branch** แล้วเลือก branch `main` และโฟลเดอร์ `/ (root)` จากนั้นกด **Save**
6. รอ 1 ถึง 2 นาที เว็บจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/home-tracker/`

## ย้ายข้อมูลจากแอพเดิมบน Claude

1. เปิดแอพเดิมใน Claude แล้วไปที่ **☰ เพิ่มเติม > ตั้งค่า > คัดลอกข้อมูล**
2. เปิดเว็บใหม่บน GitHub แล้วไปที่ **☰ เพิ่มเติม > ตั้งค่า > นำเข้าข้อมูล**
3. วางข้อมูลที่คัดลอกมา แล้วกด **นำเข้า**

ข้อมูลที่ย้ายมารวมรูปภาพด้วย

## เพิ่มเป็นแอพบนมือถือ

- **iPhone:** เปิดเว็บใน Safari แล้วกดปุ่มแชร์ > **เพิ่มไปยังหน้าจอโฮม**
- **Android:** เปิดเว็บใน Chrome แล้วกดเมนู ⋮ > **เพิ่มลงในหน้าจอหลัก**

## ข้อควรรู้

- **ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนั้น** เปิดจากมือถือกับคอมจะเห็นข้อมูลไม่ตรงกัน ใช้ปุ่มคัดลอกข้อมูลและนำเข้าข้อมูลเพื่อย้ายข้อมูลระหว่างเครื่อง
- **สำรองข้อมูลเป็นระยะ** ด้วย **☰ เพิ่มเติม > ตั้งค่า > ดาวน์โหลดไฟล์** เพราะถ้าล้างข้อมูลเบราว์เซอร์หรือลบแอพออกจากหน้าจอโฮม ข้อมูลจะหาย
- **ปุ่ม "ให้ AI คิดเมนู" จะไม่แสดง** เพราะใช้ได้เฉพาะบน Claude ส่วนเมนูที่มีอยู่ในแอพ 35 เมนูยังใช้ได้ปกติ
- **ต้องใช้อินเทอร์เน็ตครั้งแรก** เพื่อโหลดฟอนต์ ถ้าไม่มีเน็ต แอพยังใช้ได้ แต่จะแสดงด้วยฟอนต์ของเครื่องแทน
